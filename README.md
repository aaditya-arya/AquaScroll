# 🌊 AquaScroll — Cinematic Endless Descent Into the Deep Ocean

An interactive, endless-scrolling deep-ocean expedition web experience through all five NOAA pelagic zones (`0m` to `10,928m` Challenger Deep and into an infinite abyssal transect loop).

## ✨ Key Features

- **Cinematic Open-Water Viewport**:
  - Anamorphic submarine lens vignette, volumetric surface god-rays, giant background depth watermarks, and scroll-driven focus/blur parallax transitions.
- **Dual-Layer Canvas Particle & Swimmer Engine**:
  - Autonomous schooling bioluminescent *Myctophid* lanternfish that react to your ROV cursor, mid-ground glowing marine snow, hydrothermal black-smoker magma plumes (`2,400m–2,900m`), and foreground depth-of-field bokeh particles.
- **16 Custom-Engineered Animated SVG Deep-Sea Specimens**:
  - Includes *Bottlenose Dolphin*, *Green Sea Turtle*, *Giant Siphonophore*, *Bloodybelly Comb Jelly*, *Pacific Barreleye Fish*, *Vampire Squid*, *Giant Squid*, *Sperm Whale*, *Black Seadevil Anglerfish*, *Giant Tube Worm*, *Scaly-Foot Gastropod (Volcano Snail)*, *Cuvier's Beaked Whale (2,992m mammalian dive record)*, *Atolla Crown Jellyfish*, *Dumbo Octopus*, *Abyssal Sea Pig*, *Tripod Fish*, *Mariana Snailfish (8,178m)*, and *Challenger Deep Amphipod (10,928m)*.
- **Interactive Biological Adaptations & Web Audio API Hydrophone**:
  - Click any creature or its adaptation trigger to fire its real biological defense and emit a procedural sonar ping + bioluminescent shockwave.
- **Verified Scientific Data**:
  - Sourced from **NOAA**, **MBARI**, **Woods Hole Oceanographic Institution (WHOI)**, and the **Smithsonian Ocean Portal**.

## 🚀 Running Locally

Open `index.html` directly in any modern browser, or serve locally:

```bash
npx serve .
```
